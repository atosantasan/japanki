# Issue #017: [OPS] 匿名ユーザーの無制限生成とデータ増殖に対する制限・削除方針がない

- GitHub: https://github.com/atosantasan/japanki/issues/17
- 出典: `docs/issues/claude_review_01.md` 指摘 10（優先度：中）

## 1. 発生している問題
匿名サインインと RPC にレート制限がなく、セッション・プロフィールが際限なく積み上がり得る。掃除方針も未記載。

## 2. 修正要件
1. 匿名データの保持期間と掃除方針を決める。
2. レート制限の要否を設計する。

## 3. 受入条件（Acceptance Criteria）
- [ ] 匿名データの削除または保持期限が文書化されていること。
- [ ] 制限の有無と実装方針が決まっていること。
