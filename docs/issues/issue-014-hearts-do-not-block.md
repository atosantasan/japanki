# Issue #014: [UX] ハートが解答を止めずゲーミフィケーションとして機能していない

- GitHub: https://github.com/atosantasan/japanki/issues/14
- 出典: `docs/issues/claude_review_01.md` 指摘 7（優先度：中）

## 1. 発生している問題
0 ハートでも解答を止めない意図的仕様のため、ハートは表示上の飾り以上の役割を持たない。実装コストに見合うかの再確認が必要。

## 2. 修正要件
1. ハート切れで解答を止めるか、現状維持かを PRD で確定する。
2. 止める場合は UI と RPC を一致させる。

## 3. 受入条件（Acceptance Criteria）
- [ ] 設計判断が PRD に明記されていること。
- [ ] 実装が当該判断と一致していること。
