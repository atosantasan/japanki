## 3. 主要ファイル

### 3-1. `src/proxy.ts`

matcher: `/((?!api|trpc|_next|_vercel|auth|.*\\..*).*)`

1. next-intl でロケール解決
2. `attachSupabaseSession` で Cookie セッション更新（`getUser`）

API と `/auth` は matcher 外。Webhook が intl に巻き込まれない。

### 3-2. `src/components/auth/AuthProvider.tsx`

アプリ全体の認証ファサード。匿名 boot、`onAuthStateChange`、`ownedPackIds`、連携モーダル、`triggerCheckout`、保留 Checkout の自動発火を担う。

### 3-3. `src/components/quiz/QuizPlay.tsx`

1 パック分のプレイループ。RPC → `/api/phrases` → `quiz_session_questions` → 5 問 UI。

### 3-4. 環境変数（`.env.example`）

| 変数 | 公開 | 用途 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | ✅ | プロジェクト URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ✅ | Anon key |
| `SUPABASE_SECRET_KEY` | ❌ | Admin（phrases / 購入付与） |
| `STRIPE_SECRET_KEY` | ❌ | Checkout / Portal / Webhook 検証 |
| `STRIPE_WEBHOOK_SECRET` | ❌ | 署名検証 |
| `NEXT_PUBLIC_APP_URL` | ✅ | success/cancel/portal の origin |
| `CRON_SECRET` | ❌ | 匿名掃除 Cron の Bearer。Vercel が自動付与 |

Supabase Dashboard で Anonymous / Google / Email を有効化し、Redirect URL を `{APP_URL}/auth/callback` にする。Stripe Webhook は `{APP_URL}/api/stripe-webhook`。匿名掃除は `{APP_URL}/api/internal/cleanup-anonymous-users`（毎日 03:00 UTC）。

## 4. `messages/` と教材の分離

| 場所 | 対象 |
|---|---|
| `messages/{en,zh-TW,zh-CN,ko,th,fr,de,es,ja}.json` | 画面コピー。`AppMessagesSchema` |
| DB `phrases.translations` / `choices_by_lang` | 問題文の訳と選択肢。8 言語。`TranslationSchema` |

`ja` は UI 専用。クイズの訳・3択はどちらも `toContentLocale("ja") → "en"` を使う。

```json
{
  "dev": "next dev",
  "build": "next build --webpack",
  "start": "next start",

  "type-check": "tsc --noEmit",
```
