## 設計上の前提

- **現行システムの正本はコードとマイグレーション**である。本ディレクトリはその as-is 解説。
- **プロダクト意図の正本は `PRD.md` v3.2**である。実装と異なる箇所は各文書の「実装差異」に書く。実装を直すときは PRD のセキュリティ原則（Webhook のみ付与、クライアント INSERT 禁止など）を優先する。
- 未実装の将来案は「将来考慮」に分離する。
- 秘密情報（API キー、Webhook シークレット）は文書に記載しない。
