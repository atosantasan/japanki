## 3. 主要ファイル詳細

### 3-1. `src/app/page.tsx`（メインページ）

タブ切り替え型 SPA として実装。UI コンポーネント（ItemCard 等）はファイル内にインライン定義。

| タブ | 主な機能 |
|---|---|
| **在庫一覧** | カード一覧表示・タップ(+1)・長押し(-1)・カテゴリ絞り込み・登録/編集モーダル |
| **買い物リスト** | `is_shopping_list === 1` または `quantity === 0` のアイテムを表示 |
| **写真登録** | カメラ/ギャラリーから画像選択 → Gemini API 解析 → 確認フォーム |
| **マイページ** | ログイン状態表示・プレミアム状態・Stripe Checkout/Portal 連携・ログアウト |

### 3-2. `src/lib/db/`（データ層）

```
ファサード (index.ts) の主要関数:
  bootstrapInventory()       : 在庫 + appStatus 一括取得（ログイン時は /api/inventory/bootstrap）
  getItems()                 : 全アイテム取得
  insertItem(input)          : アイテム登録（ログイン時は Supabase + Storage）
  updateItem(id, input)      : アイテム更新
  deleteItem(id)             : アイテム削除（スペックも削除）
  adjustQuantity(id, delta)  : 数量変更（楽観的 UI から呼び出し、RPC 対応）
  getShoppingListItems()     : 買い物リスト取得
  findDuplicateExcluding(...)  : 重複チェック
  getAppStatus()             : AI 累計利用回数取得
  incrementAiUseCount()      : AI 利用回数 +1（月次リセットなし）
  migrateLocalToSupabaseIfNeeded() : 初回ログイン時のデータ移行
```

### 3-3. `src/middleware.ts`（Next.js Middleware）

全リクエストで実行。以下の処理を行う:

1. `updateSession()` で Supabase セッション Cookie を更新
2. `error` クエリパラメータがある場合 → `/login?error=xxx` にリダイレクト
3. OAuth の `code` パラメータがある場合 → `/auth/callback?code=xxx` に転送
4. `token_hash` パラメータがある場合 → `/auth/callback?token_hash=xxx&type=yyy` に転送

### 3-4. 環境変数（`.env`）

| 変数名 | 用途 | クライアント公開 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase プロジェクト URL | ✅ |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase Anon/Publishable Key | ✅ |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase Service Role Key（Webhook用） | ❌ |
| `STRIPE_SECRET_KEY` | Stripe 秘密鍵 | ❌ |
| `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` | Stripe 公開鍵 | ✅ |
| `STRIPE_WEBHOOK_SECRET` | Stripe Webhook 署名シークレット | ❌ |
| `STRIPE_PRICE_ID` | サブスクリプション Price ID | ❌ |
| `NEXT_PUBLIC_APP_URL` | アプリ URL（OAuth リダイレクト） | ✅ |
| `GEMINI_API_KEY` | Google Gemini API キー | ❌ |
| `GEMINI_MODEL` | Gemini モデル名（デフォルト: `gemini-2.5-flash-lite`） | ❌ |

**Expo 版との主な差異:**

| 項目 | Expo 版 | PWA 版（現行） |
|---|---|---|
| DB | expo-sqlite（端末内SQLite） | localStorage（未ログイン）/ Supabase（ログイン） |
| 課金 | RevenueCat（App Store/Google Play） | Stripe（Web決済） |
| 認証 | なし（ローカルのみ） | Supabase Auth |
| 無料制限 | 50個 / 月5回AI | 25個 / 累計10回AI |
| 画面構成 | 複数 Screen ファイル | 単一 page.tsx + モーダル |
| AI | 外部AI API（汎用） | Google Gemini API |
